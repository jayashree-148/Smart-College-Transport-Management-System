The MySQL JDBC driver (mysql-connector-j-8.x.x.jar) lives here.
You do NOT need to download it: run.sh / run.bat fetch it automatically the first time (needs internet once).
To do it by hand: download the "Platform Independent" ZIP from https://dev.mysql.com/downloads/connector/j/ and copy the .jar into this folder.

Without the driver the program still starts, in DEMO mode (reads data/demo files instead of MySQL).
